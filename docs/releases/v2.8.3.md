# v2.8.3

A follow-up patch release for quota presentation. No user configuration migration is required.

Landed as [#657](https://github.com/ndycode/codex-multi-auth/pull/657).

## Quota display

### Uninformative full windows no longer clutter compact summaries

When an upstream quota snapshot reports a full window without a label, duration, or reset timestamp, compact check/list/menu summaries now omit that window instead of displaying a misleading permanent `100%`. Useful full-window data remains visible, and the dashboard does not fall back to an empty `live session OK ()` status when both windows are uninformative ([#657](https://github.com/ndycode/codex-multi-auth/pull/657)).

## Upgrade notes

No migration is required. Install the package and confirm the version:

```bash
npm i -g codex-multi-auth
codex-multi-auth --version
```

The command should report `2.8.3`.

## Regression coverage

The release includes regression coverage for labeled and unlabeled full quota windows, missing duration/reset data, useful full-window signals, and the all-hidden dashboard fallback. The full local suite passed with 337 test files passing and 1 skipped, for 5,359 tests passing and 4 skipped.
