# v2.9.0-auth-json.1

This prerelease adds an offline way to copy an existing official Codex ChatGPT account into the multi-auth pool. It is intended for users who already have a working `auth.json` and do not want to start another OAuth flow.

```bash
npm i -g codex-multi-auth@auth-json
```

## Add an Existing Account

Import from the official Codex credential file:

```bash
codex-multi-auth add --auth-json ~/.codex/auth.json
```

Or read raw JSON from stdin without placing tokens in shell arguments:

```bash
codex-multi-auth add --raw-auth-json < ~/.codex/auth.json
```

Plain `codex-multi-auth add` opens an interactive source picker. File input defaults to the official Codex auth path, while raw TTY input is hidden and completes when the top-level JSON object closes.

## Import Behavior

- Only ChatGPT OAuth state with `access_token` and `refresh_token` is accepted.
- JWT claims are decoded locally for identity, workspace, email, and expiry hints. Import performs no network request and does not verify JWT signatures.
- Existing account matches are updated through the same deduplication rules used by login; otherwise the account is appended.
- Active and per-model-family indexes, manual pins, affinity generation, and official Codex auth files remain unchanged.
- Inputs are capped at 4 MiB, and parse errors never include nearby JSON or token values.

The source file remains in place. Imported credentials are copied into normal multi-auth storage and its backup/WAL artifacts. Run `codex-multi-auth check` afterward for live refresh and verification.
